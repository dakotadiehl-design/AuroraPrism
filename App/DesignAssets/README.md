# Aurora Design Assets (source masters)

Canonical source artwork for brand and lighting icons. **Not** compiled as an Xcode asset catalog.

| Folder | Contents |
|--------|----------|
| `VectorSources/` | Original lighting SVG masters |
| `BrandMasters/` | High-res mark/wordmark masters |
| `DocumentIcons/` | Document icon family |
| `MenuBar/` | Menubar mark sources |
| `Source/` | App icon master |

Compiled assets used by the app live in `App/Assets.xcassets/` as proper imagesets/appiconsets.
